# Week 2 Learning 

Learned JavaScript fundamentals, including variables (`var`, `let`, `const`), scope, data types, type checking, and truthy and falsy values. 
Explored operators, type coercion, equality comparisons, conditional statements, and loops. Practiced writing functions, arrow functions, and 
callbacks, along with working with arrays, objects, and nested properties.

Also learned higher-order array methods such as `map()`, `filter()`, and `find()`, along with method chaining. Explored destructuring, spread
and rest operators, and the differences between value and reference types, including shallow copying and object mutation.

**Key Takeaways:** JavaScript variables and scope, data types, operators, control flow, functions, arrays, objects, array methods,
destructuring, spread and rest operators, and value vs. reference behavior.
