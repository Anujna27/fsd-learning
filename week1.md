Week 1 Learning

Learned basic Git and GitHub, including creating repositories, uploading files, tracking changes, and making meaningful commits. Created a 
personal portfolio website using HTML and CSS, with sections for About, Skills, Projects, Education, and Contact, and added GitHub and LinkedIn 
links. Connected the repository to a deployment platform and published the website online. Also learned the basics of full-stack development,
including frontend, backend, and databases, and explored how an e-commerce order moves through validation, payment processing, database updates,
and order confirmation.

Key Takeaways: Basic HTML and CSS, Git and GitHub workflow, website deployment, full-stack architecture, and the fundamentals of e-commerce order 
processing.
